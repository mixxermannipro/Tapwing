# Sicherheitsmeldungen

Melde eine mögliche Sicherheitslücke über eine private Meldung unter „Security“ im GitHub-Repository, sofern diese Funktion verfügbar ist. Veröffentliche keine eingegebenen Texte, Zugangsdaten oder Testschlüssel in öffentlichen Meldungen.

Satzfink befindet sich in Entwicklung. Die Stabilitätsfreigabe setzt eine Prüfung der Eingabefelder, Dateiformate, Abhängigkeiten und Berechtigungen voraus. [Aktuelle Sicherheitsgrenzen](docs/PRIVACY_AND_PERMISSIONS.md)
