# Sicherheitsluecken melden

Nutze auf GitHub unter **Security -> Report a vulnerability** die private
Meldung, sofern sie verfuegbar ist. Falls die Schaltflaeche fehlt, bitte in
einem Issue ohne technische Details um einen vertraulichen Kontaktweg.

Nenne betroffene Version, Geraet, Android-Version, Auswirkungen und die
kleinsten Schritte zur Wiederholung. Verwende dafuer Testdaten. Lass
Zugangsdaten und persoenliche Daten aus der Meldung.

Die Projektlizenz steht in [LICENSE](LICENSE). Der Umgang mit Nutzerdaten
steht in [PRIVACY.md](PRIVACY.md).
